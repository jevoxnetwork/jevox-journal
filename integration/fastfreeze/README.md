# FastFreeze и история проверок

Интеграция записывает начало и окончание обычной игровой проверки в Jevox Journal. Для одной проверки используется один ID. Отдельно фиксируются отпускание, выход игрока или модератора, остановка сервера и бан, подтверждённый LiteBans. Исходный `/freeze` не принимает причину. В старых записях, где была указана причина, она останется видна.

## Сборка

Нужны JDK 21, исходный FastFreeze 1.6.0, папка `libraries` от сервера Paper или Leaf 1.21.4 (включая ASM и Gson), а также JAR LiteBans для компиляции необязательной интеграции. Команда запускается в PowerShell.

```powershell
./build.ps1 -BaseJar ./FastFreeze-1.6.0.jar -ServerLibraries ./libraries -LiteBansJar ./LiteBans.jar -OutputJar ./FastFreeze-2.0.jar
```

На остановленном игровом сервере замените JAR FastFreeze в `plugins`, оставив единственную версию плагина. Используйте существующие `plugins/FastFreeze/config.yml` и `plugins/FastFreeze/journal.yml`. Ключ `bridge-token` должен совпадать с секретом `CHECK_BRIDGE_TOKEN` проекта Cloudflare Pages. При первом запуске пример файла создаётся автоматически. Не добавляйте рабочий ключ в Git.

После запуска вызовите и отпустите тестового игрока штатными командами `/freeze` и `/unfreeze`. В разделе «Проверки» одна запись должна обновиться и показать оба времени.
